================================================================================
PYTHON BACKEND - QUICK START INSTRUCTIONS
================================================================================

Follow these steps to get your backend running in 2 minutes:

================================================================================
STEP 1: INSTALL REQUIRED PACKAGES
================================================================================

Open your terminal/command prompt and run:

pip install fastapi uvicorn bcrypt python-multipart

If you get permission errors, try:
pip install --user fastapi uvicorn bcrypt python-multipart

Or on Mac/Linux:
sudo pip install fastapi uvicorn bcrypt python-multipart

================================================================================
STEP 2: CREATE PROJECT FOLDER
================================================================================

1. Create a new folder anywhere on your computer, for example:
   C:/SkyfallBackend/  (Windows)
   ~/SkyfallBackend/   (Mac/Linux)

2. This will be your backend project folder

================================================================================
STEP 3: COPY FILES
================================================================================

Copy these 2 files from Unity project to your backend folder:

FROM: /Assets/Scripts/Backend/COMPLETE_Account.txt
TO:   Account.py  (rename to Account.py)

FROM: /Assets/Scripts/Backend/DefaultAccount.txt  
TO:   DefaultAccount.json  (rename to DefaultAccount.json)

Your folder should now contain:
- Account.py
- DefaultAccount.json

================================================================================
STEP 4: CREATE ACCOUNTS FOLDER
================================================================================

In your backend folder, create a new folder called:
Accounts

Your folder structure should be:
SkyfallBackend/
├── Account.py
├── DefaultAccount.json
└── Accounts/

================================================================================
STEP 5: (OPTIONAL) CHANGE ADMIN KEY
================================================================================

1. Open Account.py in a text editor
2. Find line 26: ADMIN_KEY = "your_secret_admin_key_12345_CHANGE_THIS"
3. Change it to something secure
4. Save the file

================================================================================
STEP 6: RUN THE BACKEND
================================================================================

1. Open terminal/command prompt
2. Navigate to your backend folder:
   cd C:/SkyfallBackend/  (Windows)
   cd ~/SkyfallBackend/   (Mac/Linux)

3. Run the server:
   python Account.py

You should see:
================================================================================
SKYFALL BACKEND SERVER STARTING
================================================================================
Admin Key: your_secret_admin_key_12345_CHANGE_THIS
IMPORTANT: Change the ADMIN_KEY to a secure value!
================================================================================
INFO:     Started server process [xxxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

The backend is now running!

================================================================================
STEP 7: TEST THE BACKEND
================================================================================

Open your web browser and go to:
http://localhost:8000

You should see:
{"log":"MeteorBackend"}

If you see this, the backend is working!

================================================================================
STEP 8: TEST ACCOUNT CREATION
================================================================================

In your browser, go to:
http://localhost:8000/login/createaccount?ID=testuser&Pass=password123

You should see:
{"log":"AccountCreated","Token":"...some random token..."}

Check your Accounts/ folder - there should now be a testuser.json file!

================================================================================
STEP 9: CONNECT UNITY
================================================================================

1. In Unity, make sure BackendServiceManager has Backend URL set to:
   http://localhost:8000

2. Run your game and try to login with:
   Username: testuser
   Password: password123

3. It should work!

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "pip: command not found"
Solution: Install Python first from python.org
          Make sure to check "Add Python to PATH" during installation

Problem: "ModuleNotFoundError: No module named 'fastapi'"
Solution: Run pip install again, make sure no errors
          Try: python -m pip install fastapi uvicorn bcrypt

Problem: "Port 8000 is already in use"
Solution: Another program is using port 8000
          Close other programs or change port in Account.py line at bottom:
          uvicorn.run(app, host="0.0.0.0", port=8001)  # Use 8001 instead

Problem: Backend starts but Unity can't connect
Solution: Check firewall settings
          Make sure URL in Unity matches: http://localhost:8000
          Check backend terminal for error messages

Problem: "FileNotFoundError: DefaultAccount.json"
Solution: Make sure DefaultAccount.json is in the same folder as Account.py
          Check the filename is exactly: DefaultAccount.json

Problem: Admin dashboard won't login
Solution: Copy the ADMIN_KEY value from Account.py
          Paste it exactly in the admin dashboard login

================================================================================
KEEPING THE BACKEND RUNNING
================================================================================

The backend needs to be running while testing your game.

To stop the backend:
- Press CTRL+C in the terminal

To run in background (advanced):
- Windows: Use pythonw Account.py
- Mac/Linux: Use screen or tmux

For production deployment, see README.txt for full deployment guide.
