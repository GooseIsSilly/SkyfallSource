================================================================================
TOKEN FLOW
================================================================================

Login Flow:
-----------
User logs in
  ↓
Backend returns token
  ↓
BackendServiceManager saves to PlayerPrefs
  ↓
Token persists across sessions
  ↓
Auto-login on next start!

Auto-Login Flow:
----------------
Game starts
  ↓
SimplerLoginManager.Start()
  ↓
TryAutoLogin() called
  ↓
Check HasStoredToken()
  ↓
If exists → ValidateToken()
  ↓
Backend: /login/connectbytoken
  ↓
If valid → OnLoginSuccess() → Show game
  ↓
If invalid → ShowLoginPanel() → Manual login

TROUBLESHOOTING GUIDE
================================================================================

Problem: Not auto-logging in
Solution: 
1. Check "Auto Login On Start" enabled
2. Check backend running
3. Check console for errors
4. Verify token saved (check PlayerPrefs)

Problem: Always shows login
Solution:
1. Backend might have restarted
2. Token expired/invalid
3. Just login again → saves new token

Problem: Loading panel stuck
Solution:
1. Backend not responding
2. Check network
3. Check backend URL
4. Look at error log

Problem: Want to test login screen
Solution:
1. Edit → Clear All PlayerPrefs
2. Restart game
3. Login screen appears!
