================================================================================
THE ROOT CAUSE
================================================================================

What Was Happening:
-------------------
1. Rocket fired with velocity (30 m/s)
2. KinematicProjectile.GetProjectilePosition() calculated position
3. Formula: position = firePosition + velocity * time + gravity * time²
4. Gravity was 20 (pulling down HARD!)
5. Rocket immediately fell to ground
6. Looked like grenade throw ❌

The Code:
---------
```csharp
// In KinematicProjectile.cs line 358:
return data.FirePosition + 
       data.InitialVelocity * time + 
       new Vector3(0f, -_gravity, 0f) * time * time * 0.5f;
       //                 ^^^^^^^^
       //                 THIS WAS THE PROBLEM!
```

Even though RocketProjectile had `_useGravity = false`, 
the KinematicProjectile base class was using `_gravity = 20`!

The Fix:
--------
Set `_gravity = 0` in RocketProjectile prefab!
Now formula becomes:
position = firePosition + velocity * time + 0
         = firePosition + velocity * time
         = STRAIGHT LINE! ✓

Formula: displacement = -0.5 × g × t²

PHYSICS FORMULA BREAKDOWN
================================================================================

Original Formula (with gravity):
---------------------------------
position = firePosition + velocity × time + ½ × gravity × time²
         = firePosition + (dir × 30) × t + ½ × (0, -20, 0) × t²
         = firePosition + velocity × t - (0, 10, 0) × t²
                                         ^^^^^^^^^^^^^^^^
                                         Pulls rocket down!

Fixed Formula (no gravity):
---------------------------
position = firePosition + velocity × time + ½ × 0 × time²
         = firePosition + (dir × 30) × t + 0
         = firePosition + velocity × t
         
Result: Straight line! ✓
