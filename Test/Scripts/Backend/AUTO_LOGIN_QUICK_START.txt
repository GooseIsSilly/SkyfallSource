OPTIONAL: ADD LOADING PANEL (2 MINUTES)
================================================================================

Makes the experience smoother!

Quick Setup:
------------
1. In your Canvas (where SimplerLoginManager is):
   - Right-click → UI → Panel
   - Name: "LoadingPanel"

2. Add text to panel:
   - Right-click LoadingPanel → UI → Text - TextMeshPro
   - Text: "Logging in..."
   - Center it
   - Font Size: 36

3. Style the panel:
   - Set Panel color: Black, Alpha 180 (semi-transparent)
   
4. Assign to SimplerLoginManager:
   - Drag LoadingPanel to "Loading Panel" field

5. Done! Now shows "Logging in..." during auto-login!

================================================================================
TROUBLESHOOTING
================================================================================

Not auto-logging in?
--------------------
→ Check "Auto Login On Start" is enabled
→ Make sure backend is running
→ Look at console logs for errors

Shows login panel every time?
------------------------------
→ Backend might have restarted (dev mode)
→ Token might have expired
→ Just login again - will save new token

Loading panel stuck?
--------------------
→ Backend not responding
→ Check backend URL in BackendServiceManager
→ Check network connection

================================================================================
ADDING LOGOUT BUTTON (OPTIONAL)
================================================================================

Want users to logout?
---------------------

1. Add button to your game menu
2. Add this script to button:

```csharp
using UnityEngine;
using TPSBR.Backend;

public class LogoutButton : MonoBehaviour
{
    public void OnClick()
    {
        BackendServiceManager.Instance.Logout(() =>
        {
            // Reload scene to show login panel
            UnityEngine.SceneManagement.SceneManager.LoadScene(
                UnityEngine.SceneManagement.SceneManager.GetActiveScene().name
            );
        });
    }
}
```

3. Attach to button
4. Done! Logout works!
