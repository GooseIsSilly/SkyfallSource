HOW IT WORKS
================================================================================

Flow:
-----
1. Player logs in as "CoolPlayer123"
   ↓
2. Backend validates and returns username
   ↓
3. SimplerLoginManager receives OnLoginSuccess("CoolPlayer123")
   ↓
4. SetPlayerNickname("CoolPlayer123") called
   ↓
5. Global.PlayerService.PlayerData.Nickname = "CoolPlayer123"
   ↓
6. Player name in game is now "CoolPlayer123"!

Result:
-------
✓ Lobby shows: "CoolPlayer123"
✓ Game shows: "CoolPlayer123"
✓ Matchmaking shows: "CoolPlayer123"
✓ Everywhere shows the backend username!

================================================================================
DELAYED RETRY SYSTEM
================================================================================

Why Needed?
-----------
Sometimes Global.PlayerService isn't ready immediately.
SimplerLoginManager handles this automatically!

How It Works:
-------------
1. Try to set nickname
2. If PlayerService not ready → Wait 1 frame
3. Try again
4. If still not ready → Log warning
5. Usually works on first or second try!

You don't need to do anything!
It's automatic and reliable!

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Nickname not set
Solution:
1. Check "Set Nickname From Backend" is enabled
2. Check console logs for warnings
3. Global.PlayerService might not be ready
4. Check that backend login succeeded

Problem: Nickname resets every login
Solution:
This is expected behavior when auto-sync is enabled!
Backend username is the source of truth.
If you want manual nicknames, disable auto-sync.

Problem: Wrong nickname displayed
Solution:
1. Check which backend account you logged in as
2. Game shows backend username exactly
3. Case-sensitive!
4. If wrong, check backend account

Problem: Delayed nickname update
Solution:
This is normal! PlayerService might initialize late.
Delayed retry will set it within 1 frame.
No action needed - automatic!

================================================================================
ADVANCED: CUSTOM DISPLAY NAMES
================================================================================

Want separate display names from backend username?
---------------------------------------------------

Option 1: Disable Auto-Sync
----------------------------
Uncheck "Set Nickname From Backend"
Players set their own display names in-game.

Option 2: Add Display Name to Backend
--------------------------------------
1. Add "DisplayName" field to backend JSON
2. Modify SetPlayerNickname() to use DisplayName instead
3. Falls back to username if no DisplayName
4. Best of both worlds!

Example Backend JSON:
{
  "AccountName": "user123",
  "DisplayName": "Epic Gamer",
  "Pass": "...",
  ...
}

Then update SimplerLoginManager:
// Get display name from backend game data
PlayerDataManager.Instance.LoadPlayerData((success, data) => {
    if (success && !string.IsNullOrEmpty(data.DisplayName))
        SetPlayerNickname(data.DisplayName);
    else
        SetPlayerNickname(username);
});
