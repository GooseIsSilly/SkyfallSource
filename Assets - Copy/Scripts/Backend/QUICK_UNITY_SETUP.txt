================================================================================
STEP 1: SETUP BACKEND MANAGERS (2 minutes)
================================================================================

1. Open scene: Assets/TPSBR/Scenes/Menu.unity

2. In Hierarchy, Right-click → Create Empty → Name it "BackendManagers"

3. With BackendManagers selected, in Inspector:
   - Click "Add Component"
   - Type: "Backend Service Manager"
   - Click to add it
   
4. Still in Inspector with BackendManagers selected:
   - Click "Add Component" again
   - Type: "Ban Check Service"
   - Click to add it

5. Check Backend Service Manager settings:
   - Backend URL should be: http://localhost:8000
   - If not, change it to that

6. Press CTRL+S to save

✓ Backend managers setup complete!

================================================================================

================================================================================

Option A: Use Your Existing UI (Recommended if you have one)
-----------------------------------------------------------
If you already have a menu UI with username/password fields:
- Skip to STEP 3
- We'll connect your existing UI instead

Option B: Create Simple Test UI (Quick test)
-----------------------------------------------------------
1. In Hierarchy, Right-click → UI → Canvas (if you don't have one)

2. Right-click Canvas → UI → Panel → Name it "TestLoginPanel"

3. Right-click TestLoginPanel → UI → Input Field - TextMeshPro
   - Name it: "UsernameInput"
   - Change Placeholder to: "Username"

4. Right-click TestLoginPanel → UI → Input Field - TextMeshPro
   - Name it: "PasswordInput"
   - Change Placeholder to: "Password"
   - Change Content Type to: "Password"

5. Right-click TestLoginPanel → UI → Button - TextMeshPro
   - Name it: "LoginButton"
   - Change text to: "Login"

6. Right-click TestLoginPanel → UI → Button - TextMeshPro
   - Name it: "CreateAccountButton"
   - Change text to: "Create Account"

7. Right-click TestLoginPanel → UI → Text - TextMeshPro
   - Name it: "FeedbackText"
   - Clear the text (make it empty)
   - Change color to Yellow or Red for visibility

✓ Login UI created!

================================================================================
STEP 3: CONNECT UI TO BACKEND (1 minute)
================================================================================

1. Select "TestLoginPanel" (or your login panel) in Hierarchy

2. In Inspector, click "Add Component"

3. Type: "Simple Login UI"

4. Click to add it

5. Now drag and drop each UI element:
   - Drag UsernameInput → to "Username Input" slot
   - Drag PasswordInput → to "Password Input" slot
   - Drag LoginButton → to "Login Button" slot
   - Drag CreateAccountButton → to "Create Account Button" slot
   - Drag FeedbackText → to "Feedback Text" slot
   - (Optional) Drag TestLoginPanel → to "Login Panel" slot (hides panel after login)

6. Press CTRL+S to save

✓ UI connected to backend!

================================================================================
TROUBLESHOOTING
================================================================================

Error: "Backend service not available"
Fix: Make sure BackendManagers GameObject exists with components attached

Error: "Network error" or no response
Fix: 1. Check Python backend is running (look at terminal)
     2. Check Backend URL is exactly: http://localhost:8000
     3. Try using: http://127.0.0.1:8000 instead

Error: "Username must be at least 3 characters"
Fix: Use username with 3+ characters

Error: "Password must be at least 9 characters"
Fix: Use password with 9+ characters (backend requirement)

Nothing happens when clicking buttons:
Fix: Check Console (Window → General → Console) for error messages
     Make sure all UI references are assigned in Inspector

NEXT STEPS - INTEGRATE WITH YOUR GAME
================================================================================

Now that login works, you need to connect it to your game flow:

1. FIND YOUR GAME START CODE
   Look for where you start the game or connect to Photon
   Likely in: Assets/TPSBR/Scripts/UI/MenuViews/ or similar

2. ADD LOGIN CHECK
   Before starting game, check if player is logged in:
   
   if (!BackendServiceManager.Instance.HasStoredToken())
   {
       // Show login UI
       // Don't start game yet
       return;
   }

3. VALIDATE TOKEN
   Before connecting to Photon:
   
   BackendServiceManager.Instance.ValidateToken((success, username) =>
   {
       if (success)
       {
           // Start game with this username
           StartGame(username);
       }
       else
       {
           // Show login UI
       }
   });

4. USE USERNAME IN GAME
   When creating player in Photon:
   
   string username = BackendServiceManager.Instance.GetStoredUsername();
   // Use this as player nickname
