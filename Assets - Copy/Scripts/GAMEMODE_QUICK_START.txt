================================================================================
ADDING MORE GAMEMODES (3 EASY STEPS)
================================================================================

Step 1: Update Enum
--------------------
File: GameplayMode.cs (line 26)

public enum EGameplayType
{
    None,
    BattleRoyale,
    TeamDeathmatch,    // ← Add this
}

Step 2: Add to Array
--------------------
File: UIFortniteLobbyView.cs (find _availableGamemodes)

Change:
private EGameplayType[] _availableGamemodes = new EGameplayType[] { 
    EGameplayType.BattleRoyale 
};

To:
private EGameplayType[] _availableGamemodes = new EGameplayType[] { 
    EGameplayType.BattleRoyale,
    EGameplayType.TeamDeathmatch
};

Step 3: Add Display Name
-------------------------
File: UIFortniteLobbyView.cs (find GetGamemodeName)

Add case:
case EGameplayType.TeamDeathmatch:
    return "TEAM DEATHMATCH";

Done! Now you have 2 gamemodes to cycle through!

CODE OVERVIEW
================================================================================

When Button Clicked:
--------------------
1. Increment _currentGamemodeIndex
2. Wrap around to 0 if at end
3. Set _gameplayType to selected mode
4. Update display text
5. Log change

Display Update:
---------------
GetGamemodeName() maps enum to text:
BattleRoyale → "BATTLE ROYALE - SOLO"
TeamDeathmatch → "TEAM DEATHMATCH"
etc.

Integration:
------------
Play button already uses _gameplayType:
- Searches for matching sessions
- Creates session with correct type
- No extra work needed!
