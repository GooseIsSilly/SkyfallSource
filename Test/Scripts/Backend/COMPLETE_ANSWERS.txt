----------------------

Summary:

STEP 2: Add PlayerDataManager to Unity
---------------------------------------
1. Create GameObject: "PlayerDataManager"
2. Add Component: "Player Data Manager"
3. Done!

STEP 3: Use in Your Game
-------------------------
After login:

PlayerDataManager.Instance.LoadPlayerData((success, data) =>
{
    if (success)
    {
        int level = data.Level;           // Player's level
        int coins = data.CloudCoins;      // Player's coins
        string[] skins = data.OwnedSkins; // Owned skins
        
        // Update your UI here
    }
});

Award coins:
PlayerDataManager.Instance.AddCoins(100);

Award XP:
PlayerDataManager.Instance.AddXP(500); // Auto-levels up!

Unlock skin:
PlayerDataManager.Instance.UnlockSkin("RareSkin01");

Check if owns skin:
bool hasIt = PlayerDataManager.Instance.HasSkin("RareSkin01");

COMMON INTEGRATION POINTS
================================================================================

Where to add data sync in YOUR game:

1. After Login:
   - Load player data
   - Update UI with level/coins
   - Load equipped skin model

2. After Match Ends:
   - Calculate rewards (coins, XP)
   - Award to player
   - Show rewards screen

3. In Shop:
   - Check if player has enough coins
   - Deduct coins
   - Unlock skin
   - Save data

4. Level Up:
   - Subscribe to OnLevelChanged event
   - Show level up animation
   - Award rewards (if any)

5. Before Quit:
   - Save all data
   - Logout

PRODUCTION TIPS

UX:
- Show "Saving..." indicators

- Auto-retry failed saves
- Sync on important events only
