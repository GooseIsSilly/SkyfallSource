================================================================================
NEW METHODS AVAILABLE
================================================================================

Work with CharacterData objects:
---------------------------------
GetCharacterByID(string id)                    → Find CharacterData by ID
GetAllCharacters()                             → All CharacterData in game
GetOwnedCharacters()                           → Owned CharacterData array
GetLockedCharacters()                          → Locked CharacterData array
GetEquippedCharacter()                         → Currently equipped CharacterData

HasCharacter(CharacterData character)          → Check if owned
CanAfford(CharacterData character)             → Check if can buy

UnlockCharacter(CharacterData, callback)       → Unlock character
SetEquippedCharacter(CharacterData)            → Equip character
PurchaseCharacter(CharacterData, callback)     → Buy with coins

Old methods still work:
-----------------------
HasCharacter(string characterID)               → Still works
UnlockCharacterByID(string id, callback)       → Still works
SetEquippedCharacterByID(string id)            → Still works

================================================================================
HOW IT WORKS
================================================================================

1. CharacterData Asset Setup:
   - characterID: "soldier66" (unique ID, saved to backend)
   - displayName: "Soldier 66" (shown in UI)
   - price: 1000 (CloudCoins cost)
   - unlockedByDefault: true/false (auto-unlock)
   - agentID: "Soldier_01" (matches AgentSettings)

2. Backend Storage:
   {
     "OwnedSkins": ["soldier66", "marine"],
     "EquippedSkin": "soldier66"
   }

3. Unity Code:
   CharacterData character = PlayerDataManager.Instance.GetCharacterByID("soldier66");
   bool owned = PlayerDataManager.Instance.HasCharacter(character);

================================================================================
QUICK EXAMPLE
================================================================================

// Get equipped character
CharacterData equipped = PlayerDataManager.Instance.GetEquippedCharacter();
if (equipped != null)
{
    Debug.Log($"Playing as: {equipped.displayName}");
    SpawnCharacter(equipped.agentID);
}

// Show all owned characters
CharacterData[] owned = PlayerDataManager.Instance.GetOwnedCharacters();
foreach (var character in owned)
{
    Debug.Log($"You own: {character.displayName}");
}

// Purchase a character
CharacterData soldier = PlayerDataManager.Instance.GetCharacterByID("soldier66");
PlayerDataManager.Instance.PurchaseCharacter(soldier, (success, message) =>
{
    if (success)
    {
        Debug.Log($"Bought {soldier.displayName}!");
    }
});

================================================================================
DEFAULT CHARACTERS
================================================================================

Characters with "unlockedByDefault" checked will be automatically unlocked
when player first logs in!

To set a default character:
1. Select CharacterData asset (e.g., marine.asset)
2. Check "Unlocked By Default"
3. Save

Next time a new player logs in, they'll own it automatically!

================================================================================
TESTING
================================================================================

1. Select both CharacterData assets (marine, soldier66)
2. In Inspector, check their characterID values
3. Set one to "unlockedByDefault = true"
4. Play game and login
5. Run: PlayerDataManager.Instance.GetOwnedCharacters()
6. Should see the default character unlocked!
