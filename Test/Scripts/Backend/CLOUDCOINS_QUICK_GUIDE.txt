================================================================================
HOW TO GIVE/TAKE COINS
================================================================================

Give Coins:
-----------
PlayerDataManager.Instance.AddCoins(100);

Take Coins:
-----------
PlayerDataManager.Instance.AddCoins(-50);

Check Balance:
--------------
int coins = PlayerDataManager.Instance.CurrentData.CloudCoins;

Purchase Check:
---------------
CharacterData character = ...;
bool canAfford = PlayerDataManager.Instance.CanAfford(character);

if (canAfford)
{
    PlayerDataManager.Instance.PurchaseCharacter(character);
}

================================================================================
INTEGRATION EXAMPLES
================================================================================

Shop Purchase:
--------------
PlayerDataManager.Instance.AddCoins(-1000, (success, newTotal) => {
    if (success) {
        UnlockSkin("RareSkin01");
        Debug.Log($"Remaining: {newTotal} coins");
    }
});

Match Reward:
-------------
void OnMatchEnd(int placement)
{
    int reward = placement == 1 ? 500 : 100;
    PlayerDataManager.Instance.AddCoins(reward);
}

Daily Bonus:
------------
PlayerDataManager.Instance.AddCoins(250);
ShowPopup("+250 CloudCoins!");

================================================================================
CUSTOMIZATION
================================================================================

Change Position:
----------------
Select: CloudCoinsPanel in Hierarchy
Adjust: Anchored Position X/Y

Change Text Size:
-----------------
Select: CloudCoinsText
Change: Font Size (default 36)

Change Color:
-------------
Select: CloudCoinsText or CoinIcon
Modify: Color property

Add Coin Sprite:
----------------
Select: CoinIcon
Drag sprite to: Image > Source Image

================================================================================
EVENTS YOU CAN USE
================================================================================

When Coins Change:
------------------
PlayerDataManager.Instance.OnCoinsChanged += (newAmount) => {
    Debug.Log($"Coins updated: {newAmount}");
};

When Level Up:
--------------
PlayerDataManager.Instance.OnLevelChanged += (newLevel) => {
    ShowLevelUpPopup(newLevel);
};

When Data Loads:
----------------
PlayerDataManager.Instance.OnDataLoaded += (data) => {
    Debug.Log($"Loaded {data.CloudCoins} coins");
};

================================================================================
BACKEND ENDPOINTS
================================================================================

Add Coins:
GET /account/addcoins?Token=XXX&Amount=100

Add XP:
GET /account/addxp?Token=XXX&Amount=500

Get Data:
GET /account/getgamedata?Token=XXX

Update Data:
POST /account/updategamedata
Body: { Token, Level, XP, CloudCoins, ... }

================================================================================
TROUBLESHOOTING
================================================================================

Not showing?
- Check CloudCoinsPanel is active
- Check CloudCoinsText is assigned in UIFortniteLobbyView
- Check PlayerDataManager exists in scene

Shows 0?
- Check backend is running
- Check login successful
- Check backend JSON has CloudCoins field
- Run LoadPlayerData() manually

Not updating?
- Check PlayerDataManager.Instance exists
- Check OnCoinsChanged subscribed
- Check Console for errors
