HOW IT WORKS NOW
================================================================================

When Shop Opens:
----------------
1. ModernShopManager.OnOpen() is called
2. Loads player data from backend
3. Updates coin display with backend value
4. Refreshes all shop cards with backend ownership

When Purchase Clicked:
----------------------
1. Checks if player owns character (from backend)
2. PlayerDataManager.PurchaseCharacter() is called
3. Backend deducts coins and unlocks character
4. Shop refreshes automatically
5. Coin display updates automatically

When Coins Change (from anywhere):
----------------------------------
1. OnCoinsChanged event fires
2. Shop automatically updates coin display
3. Shop refreshes all card buttons (enable/disable)

================================================================================
TOGGLING BACKEND SYNC
================================================================================

Both ModernShopManager and ModernShopCard have _useBackendSync toggle.

To Disable Backend Sync:
-------------------------
1. Select ModernShop in Hierarchy
2. Find ModernShopManager component
3. Uncheck "Use Backend Sync"
4. Shop will use local CloudCoinSystem instead

When Disabled:
--------------
- Shop uses _playerData.CoinSystem (local)
- Shop uses _playerData.ShopSystem (local)
- No persistence across sessions
- Starts with 0 coins (was 100, now fixed)

When Enabled (Default):
-----------------------
- Shop uses PlayerDataManager (backend)
- Shop syncs with backend JSON
- Full persistence across sessions
- Starts with backend value (usually 0)

TROUBLESHOOTING
================================================================================

Shop shows wrong amount:
-------------------------
- Check ModernShopManager has "Use Backend Sync" checked
- Check PlayerDataManager exists in scene
- Check backend is running
- Check logged in successfully

Shop shows 100/750 instead of 0:
---------------------------------
- Old CloudCoinSystem default was 100
- This is now fixed to 0
- Delete PlayerPrefs to reset local data
- Or create new account

Purchase doesn't work:
----------------------
- Check backend is running
- Check has enough coins
- Check character isn't already owned
- Check Console for errors

Coin count different in lobby vs shop:
---------------------------------------
- Both should use backend now
- Check both have backend sync enabled
- Restart game and login fresh

- Adds/removes coins
- Returns new total

- Unlocks character
- Called on purchase
