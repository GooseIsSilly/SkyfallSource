================================================================================
UNITY LOGIN SETUP - STEP BY STEP GUIDE
================================================================================

Your backend is working! Now let's connect it to Unity and create a login system.

================================================================================
PART 1: SETUP BACKEND MANAGERS (5 minutes)
================================================================================

STEP 1: Open Your Menu Scene
-----------------------------
1. In Unity, open: Assets/TPSBR/Scenes/Menu.unity
2. This is where players will login before joining the game

STEP 2: Create Backend Managers GameObject
-----------------------------
1. Right-click in Hierarchy → Create Empty
2. Rename it to: "BackendManagers"
3. With BackendManagers selected, click "Add Component"
4. Search for: "Backend Service Manager"
5. Add it (from TPSBR.Backend namespace)
6. Click "Add Component" again
7. Search for: "Ban Check Service"
8. Add it

STEP 3: Configure Backend Service Manager
-----------------------------
With BackendManagers selected, in the Inspector you'll see:

Backend Service Manager Component:
- Backend URL: http://localhost:8000
- Api Timeout: 10
- Retry Attempts: 3

Make sure Backend URL is: http://localhost:8000

STEP 4: Configure Ban Check Service
-----------------------------
With BackendManagers still selected, scroll down to:

Ban Check Service Component:
- Ban Check Interval: 30
- Check On Start: ✓ (checked)
- On Player Banned: (leave empty for now, we'll set this up later)

STEP 5: Save the Scene
-----------------------------
Press CTRL+S (CMD+S on Mac) to save

✓ Backend managers are now set up!

================================================================================
PART 2: CREATE SIMPLE LOGIN UI (10 minutes)
================================================================================

You already have UI in your game, but let's create a simple test login first.

STEP 1: Create Login Panel
-----------------------------
1. In Menu scene Hierarchy, find your Canvas (or create one if missing)
2. Right-click on Canvas → UI → Panel
3. Rename it to: "LoginPanel"
4. Make it fullscreen (stretch to fill canvas)

STEP 2: Add Username Input
-----------------------------
1. Right-click LoginPanel → UI → Input Field - TextMeshPro
2. Rename it to: "UsernameInput"
3. Position it in the center-top area
4. In Inspector, find the placeholder text and change it to: "Username"

STEP 3: Add Password Input
-----------------------------
1. Right-click LoginPanel → UI → Input Field - TextMeshPro
2. Rename it to: "PasswordInput"
3. Position it below UsernameInput
4. In Inspector:
   - Find the placeholder text → change to: "Password"
   - Find "Content Type" → change to: "Password"

STEP 4: Add Login Button
-----------------------------
1. Right-click LoginPanel → UI → Button - TextMeshPro
2. Rename it to: "LoginButton"
3. Position it below PasswordInput
4. Change button text to: "Login"

STEP 5: Add Create Account Button
-----------------------------
1. Right-click LoginPanel → UI → Button - TextMeshPro
2. Rename it to: "CreateAccountButton"
3. Position it below LoginButton
4. Change button text to: "Create Account"

STEP 6: Add Feedback Text
-----------------------------
1. Right-click LoginPanel → UI → Text - TextMeshPro
2. Rename it to: "FeedbackText"
3. Position it at the bottom of LoginPanel
4. Change text to: "" (empty)
5. Change color to white or red for visibility

Your UI hierarchy should look like:
Canvas
└── LoginPanel
    ├── UsernameInput
    ├── PasswordInput
    ├── LoginButton
    ├── CreateAccountButton
    └── FeedbackText

PART 5: CONNECT TO YOUR EXISTING GAME (10 minutes)
================================================================================

Now that login works, let's connect it to your actual game flow.

STEP 1: Find Your Existing Game Start Logic
-----------------------------
You probably have code that starts the game or connects to Photon Fusion.
It's likely in one of these places:
- Assets/TPSBR/Scripts/UI/MenuViews/
- Assets/TPSBR/Scripts/Core/
- Assets/TPSBR/Scripts/Networking/

Look for scripts that handle:
- "Start Game" button
- Photon connection
- Scene loading to game scene

STEP 2: Add Login Check Before Game Start
-----------------------------
In that script, before connecting to Photon or starting game, add:

using TPSBR.Backend;

// Before starting game:
if (!BackendServiceManager.Instance.HasStoredToken())
{
    Debug.LogWarning("Player not logged in!");
    // Show login UI
    // Don't start game
    return;
}

// Validate the token
BackendServiceManager.Instance.ValidateToken((success, username) =>
{
    if (success)
    {
        // Token is valid, continue to game
        Debug.Log($"Logged in as: {username}");
        StartGame();
    }
    else
    {
        // Token invalid, show login UI
        Debug.LogWarning("Session expired, please login");
        // Return to login screen
    }
});

STEP 3: Pass Username to Photon
-----------------------------
When creating the Photon session, use the authenticated username:

string username = BackendServiceManager.Instance.GetStoredUsername();

// Use this username as player nickname in Photon
// Example: playerData.Nickname = username;

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Backend service not available" error
Solution: Make sure BackendManagers GameObject exists with components

Problem: Nothing happens when clicking Login
Solution: Check Console for errors
         Make sure backend is running (check terminal)
         Make sure Backend URL is exactly: http://localhost:8000

Problem: "Network error" when logging in
Solution: Backend might not be running - check terminal
         Check Backend URL in BackendServiceManager component
         Try: http://127.0.0.1:8000 instead of localhost

Problem: Login works but game doesn't start
Solution: You need to integrate with your existing game start logic
         Follow PART 5 above

Problem: Can't find BackendServiceManager in Add Component
Solution: Make sure the C# script compiled successfully
         Check Console for compilation errors
         The script is at: Assets/Scripts/Backend/BackendServiceManager.cs
