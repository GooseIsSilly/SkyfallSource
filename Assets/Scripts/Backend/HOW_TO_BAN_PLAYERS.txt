================================================================================
HOW TO BAN PLAYERS - COMPLETE GUIDE
================================================================================

There are 3 ways to ban players:

================================================================================
METHOD 1: ADMIN DASHBOARD (EASIEST - RECOMMENDED)
================================================================================

STEP 1: Open Admin Dashboard
-----------------------------
1. Find the file: Assets/Scripts/Backend/admin_dashboard.html
2. Copy it to your backend folder (where Account.py is)
3. Open it in a web browser (Chrome, Firefox, etc.)

STEP 2: Login to Dashboard
-----------------------------
1. You'll see "Admin Login" screen
2. Enter Admin Key: your_secret_admin_key_12345_CHANGE_THIS
   (This is from your Account.py file, line 26)
3. Click "Login"

STEP 3: Ban a Player
-----------------------------
1. Click "Bans" tab at top
2. Click "Ban Player" button
3. Fill in:
   - Player Username: (e.g., "Novafy")
   - Ban Reason: (e.g., "Hacking/Cheating")
   - Permanent Ban: Check for permanent, uncheck for temporary
   - If temporary: Select expiration date/time
4. Click "Ban Player"

DONE! Player is now banned!

STEP 4: Test It
-----------------------------
1. Try to login with that account in Unity
2. Should see: "Account banned. Reason: Hacking/Cheating"
3. Player CANNOT login!

If player is already in-game:
- Within 30 seconds, they'll be kicked
- Message shown: "You have been banned"

================================================================================
METHOD 2: VIA WEB BROWSER (NO DASHBOARD NEEDED)
================================================================================

Just paste this URL in browser (replace values):

http://localhost:8000/admin/ban?AdminKey=your_secret_admin_key_12345_CHANGE_THIS&PlayerID=USERNAME&Reason=Hacking

Example:
http://localhost:8000/admin/ban?AdminKey=your_secret_admin_key_12345_CHANGE_THIS&PlayerID=Novafy&Reason=Cheating

For temporary ban (expires in 24 hours):
http://localhost:8000/admin/ban?AdminKey=your_secret_admin_key_12345_CHANGE_THIS&PlayerID=Novafy&Reason=Toxic&ExpiresAt=2024-01-16%2015:30:00

Date format: YYYY-MM-DD HH:MM:SS (URL encoded)

================================================================================
METHOD 3: FROM UNITY CODE (FOR AUTO-BAN SYSTEMS)
================================================================================

You can call the ban endpoint from Unity:

using UnityEngine.Networking;

string adminKey = "your_secret_admin_key_12345_CHANGE_THIS";
string playerID = "HackerUsername";
string reason = "Auto-detected aimbot";

string url = $"http://localhost:8000/admin/ban?AdminKey={adminKey}&PlayerID={playerID}&Reason={UnityWebRequest.EscapeURL(reason)}";

UnityWebRequest request = UnityWebRequest.Get(url);
yield return request.SendWebRequest();

if (request.result == UnityWebRequest.Result.Success)
{
    Debug.Log("Player banned!");
}

================================================================================
HOW THE BAN SYSTEM WORKS
================================================================================

When you ban a player:

1. Backend updates player's JSON file:
   - Sets IsBanned = true
   - Saves ban reason
   - Saves ban date/time
   - Saves expiration (if temporary)

2. Backend creates ban record:
   - Saves to /Bans/PlayerName.json
   - Contains all ban details

3. When player tries to login:
   - Backend checks if player is banned
   - If banned: Login REJECTED with ban message
   - If not banned: Login allowed

4. For players already in-game:
   - BanCheckService checks every 30 seconds
   - If ban detected: Player kicked immediately
   - Shows ban message and returns to menu

================================================================================
UNBANNING PLAYERS
================================================================================

Via Admin Dashboard:
1. Go to "Bans" tab
2. Find the player
3. Click "Unban" button
4. Player can now login again!

Via Browser:
http://localhost:8000/admin/unban?AdminKey=your_secret_admin_key_12345_CHANGE_THIS&PlayerID=USERNAME

The ban record moves to /Bans/Archive/

================================================================================
TEMPORARY BANS
================================================================================

When creating a temporary ban:

1. Set expiration date/time
2. Player is banned until that time
3. After expiration, they can login automatically
4. Ban is automatically removed when expired

Example: Ban for 24 hours
- Banned at: 2024-01-15 10:00:00
- Expires at: 2024-01-16 10:00:00
- At 10:01 on Jan 16, player can login again

BAN SECURITY
================================================================================

Important security notes:

1. CHANGE THE ADMIN KEY!
   - Edit Account.py line 26
   - Use something long and random
   - Never share it with players

2. Keep admin dashboard password protected
   - Don't share admin key

   - Use HTTPS for backend
   - Store admin key in environment variable
   - Add IP whitelist for admin endpoints

CHECKING IF PLAYER IS BANNED (FROM UNITY)
================================================================================

If you want to check ban status from Unity code:

BackendServiceManager.Instance.CheckBanStatus((isBanned, reason, expiresAt) =>
{
    if (isBanned)
    {
        Debug.Log($"Player is banned! Reason: {reason}");
        Debug.Log($"Expires: {expiresAt}");
    }
    else
    {
        Debug.Log("Player is not banned");
    }
});

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "InvalidAdminKey" error
Solution: Check admin key in Account.py matches what you're entering
         Copy it exactly, it's case-sensitive

Problem: Player not kicked after ban
Solution: Make sure BanCheckService is running in game scene
         Check ban check interval (default 30 seconds)
         Player will be kicked on next check

Problem: Can't see bans in dashboard
Solution: Check backend is running
         Check admin key is correct
         Check /Bans/ folder exists in backend directory

Problem: Temporary ban not expiring
Solution: Check date format is correct: YYYY-MM-DD HH:MM:SS
         Check server time is correct
         Player must try to login for ban to be checked
