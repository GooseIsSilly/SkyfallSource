HOW IT ALL WORKS TOGETHER
================================================================================

Complete Player Journey:
------------------------

1. FIRST TIME PLAYER
   Game starts
   → No token → Login panel appears
   → Player creates account "CoolGamer"
   → Backend creates account with password hash
   → Token generated and returned
   → Token saved to PlayerPrefs
   → Nickname auto-set to "CoolGamer"
   → Player data loaded from backend
   → Lobby shows name "CoolGamer" and CloudCoins
   → Ready to play!

2. RETURNING PLAYER
   Game starts
   → Token found → Auto-validates with backend
   → Token valid → Auto-login! (no login screen)
   → Nickname auto-set to "CoolGamer"
   → Player data loaded from backend
   → Lobby shows updated stats
   → Ready to play immediately!

3. DURING GAMEPLAY
   Player earns CloudCoins
   → Saved to backend
   → Shop syncs with backend
   → Player buys skin
   → Backend updated with new skin
   → Owned skins synced
   → Lobby shows new skin
   → All data persists!

4. BANNED PLAYER
   Player logs in
   → Token validates
   → Backend detects ban
   → Ban message displayed with reason
   → Player logged out
   → Cannot play until unbanned
