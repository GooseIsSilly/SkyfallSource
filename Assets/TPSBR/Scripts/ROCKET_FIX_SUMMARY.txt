⚡ ROCKET LAUNCHER - FIXED! ✅
================================================================================

PROBLEM: Rocket shot like grenade, didn't explode
SOLUTION: Fixed collision detection

================================================================================
WHAT WAS WRONG
================================================================================

❌ Rigidbody was Kinematic
   → Kinematic rigidbodies don't detect collisions!
   → OnCollisionEnter never triggered
   → No explosion!

❌ Projectile speed was 100 m/s
   → Too fast! Like a bullet!
   → Should be 30 m/s (slow rocket)

❌ Collider too big (0.5 radius)
   → Could hit things weirdly

❌ Collision detection was Discrete
   → Could miss fast collisions

================================================================================
WHAT I FIXED
================================================================================

✅ Rigidbody.isKinematic = false
   → Now detects collisions!

✅ CollisionDetectionMode = Continuous
   → Better collision detection!

✅ Interpolation = Interpolate
   → Smoother movement!

✅ Projectile Speed = 30 m/s
   → Slow, visible rocket (Fortnite-like!)

✅ Collider Radius = 0.2
   → Appropriate size for rocket!

✅ Prefab Active = true
   → Will spawn correctly!
