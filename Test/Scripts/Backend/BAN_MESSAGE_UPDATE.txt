================================================================================
HOW IT WORKS
================================================================================

1. Player tries to login with banned account
2. Backend returns ban info:
   - reason: "Why they were banned"
   - expiresAt: "2024-12-25 15:30:00" or None for permanent

3. Unity formats it nicely using FormatBanMessage()
4. Message is shown in login UI feedback text

================================================================================
BACKEND RESPONSE FORMAT
================================================================================

When player is banned, backend returns:

{
    "log": "AccountBanned",
    "reason": "Cheating with aimbot",
    "expiresAt": "2024-12-25 15:30:00"
}

Or for permanent ban:

{
    "log": "AccountBanned",
    "reason": "Repeated violations",
    "expiresAt": null
}

================================================================================
WHERE BAN MESSAGES APPEAR
================================================================================

1. Login Screen
   - Player enters username/password
   - Clicks login
   - If banned, shows formatted message

2. Auto-Login (Token Validation)
   - Player has saved token
   - Game auto-validates on start
   - If banned, shows formatted message and clears token

3. In-Game Ban Detection
   - Player gets banned while playing
   - BanCheckService detects it
   - Kicks player with ban message

================================================================================
CUSTOMIZING THE MESSAGE
================================================================================

You can customize the ban message format in BackendServiceManager.cs:

private string FormatBanMessage(string reason, string expiresAt)
{
    string message = "YOU ARE BANNED";  // ← Change this header
    
    if (!string.IsNullOrEmpty(reason))
    {
        message += $"\n\nReason: {reason}";  // ← Change format
    }
    
    if (!string.IsNullOrEmpty(expiresAt) && expiresAt != "None")
    {
        message += $"\n\nBan Duration: Until {expiresAt}";  // ← Change format
    }
    else
    {
        message += $"\n\nBan Duration: Permanent";  // ← Change format
    }
    
    return message;
}

Example customization:
----------------------
message = "⛔ ACCOUNT SUSPENDED ⛔";
message += $"\n\n📋 Violation: {reason}";
message += $"\n\n⏰ Expires: {expiresAt}";

Or more formal:
---------------
message = "Access Denied - Account Banned";
message += $"\n\nViolation Type: {reason}";
message += $"\n\nReinstated On: {expiresAt}";

================================================================================
UI DISPLAY TIPS
================================================================================

The ban message includes newlines (\n) for formatting.

Make sure your UI Text component supports multi-line:
- TextMeshPro: Enable "Wrapping" and increase "Vertical Overflow"
- Legacy Text: Check "Rich Text" and set appropriate size

For better visuals:
-------------------
1. Use a dedicated "Ban Panel" with red background
2. Large, bold red text for "YOU ARE BANNED"
3. Smaller white text for reason and duration
4. Add a "Contact Support" button

Example in SimpleLoginUI.cs:
----------------------------
if (message.Contains("YOU ARE BANNED"))
{
    feedbackText.color = Color.red;
    feedbackText.fontSize = 24;
}

================================================================================
DURATION FORMATTING
================================================================================

Backend stores: "2024-12-25 15:30:00"
Unity shows: "Until 2024-12-25 15:30:00"

You can make it friendlier:

Option 1: Calculate time remaining
-----------------------------------
Instead of: "Until 2024-12-25 15:30:00"
Show: "Ban expires in 3 days, 5 hours"

Option 2: Parse to friendly format
-----------------------------------
Instead of: "Until 2024-12-25 15:30:00"
Show: "Until December 25, 2024 at 3:30 PM"

(This requires DateTime parsing in FormatBanMessage method)
