================================================================================
HOW TO DEBUG
================================================================================

Test Steps:
-----------
1. Start game in Play mode
2. Open Console window (Ctrl+Shift+C)
3. Clear console
4. Fire rocket at ground near you
5. Watch console logs

What to Look For:
-----------------

Log 1: Explosion Position
-------------------------
"[RocketProjectile] Exploding at (x, y, z)"
→ Shows where explosion happened

Log 2: Explosion Settings
--------------------------
"[RocketProjectile] Explode called. Radius: 8.35, Damage: 100, HitMask: X"
→ HitMask should be 192 or 384 (includes Agent layer)
→ If different, explosion won't hit players!

Log 3: Owner Detection
----------------------
"[RocketProjectile] Owner: PlayerName"
→ Should show your player's name
→ If "null", self-damage detection won't work!

Log 4: Colliders Found
-----------------------
"[RocketProjectile] Found X colliders in explosion radius"
→ Should be > 0 if you're in range
→ If 0, you're too far or layer mask wrong!

Log 5: Each Collider
--------------------
"[RocketProjectile] Checking collider 0: [name], Layer: Agent"
→ Should include your player colliders
→ Layer should be "Agent" for players

Log 6: IHitTarget Check
-----------------------
"[RocketProjectile] No IHitTarget found on [name]"
→ If you see this for your player, something's wrong!
→ Player should have IHitTarget component

Log 7: Self Detection
---------------------
"[RocketProjectile] HitAgent: PlayerName, IsSelf: true"
→ Should say "true" when it's your player
→ If "false", self-damage multiplier won't apply!

Log 8: Damage Applied
---------------------
"[RocketProjectile] Applying 75 damage to PlayerName (isSelf: true)"
→ Should show damage being applied to you
→ isSelf should be "true"
→ Damage should be reduced (75% of base)

================================================================================
POSSIBLE ISSUES AND FIXES
================================================================================

Issue 1: "Found 0 colliders"
-----------------------------
Problem: OverlapSphere not finding anything
Possible Causes:
→ Explosion radius too small (should be 8.35)
→ Layer mask doesn't include "Agent"
→ You're too far from explosion

Check:
- _explosionRadius = 8.35
- _explosionHitMask includes "Agent" layer
- Distance from explosion < 8.35m

Fix:
Make sure _explosionHitMask includes Agent layer!

Issue 2: "No IHitTarget found"
-------------------------------
Problem: Player doesn't have IHitTarget component
Possible Cause:
→ Player prefab missing component

Check:
- Player has Agent component
- Agent implements IHitTarget interface

This should already be correct in TPSBR!

Issue 3: "IsSelf: false" when it should be true
------------------------------------------------
Problem: Self-detection not working
Possible Causes:
→ Owner is null
→ HitAgent doesn't match owner
→ GetComponentInParent not finding Agent

Check:
- "Owner: [name]" log shows correct player
- HitAgent found on collider
- Both are same Agent instance

Fix:
Check owner initialization in Fire() method

Issue 4: Damage is 0
--------------------
Problem: Damage calculated to 0
Possible Causes:
→ Distance from explosion > radius
→ Damage multiplier calculation wrong

Check:
- Distance to explosion point
- Should be < 8.35m
- Damage = base * (1 - distance/radius) * selfMultiplier

Issue 5: "_canDamageSelf = false"
----------------------------------
Problem: Self-damage disabled
Check:
- _canDamageSelf = true (should be!)
- _selfDamageMultiplier = 0.75

This should be correct in your prefab!

Issue 6: HitMask Wrong Value
-----------------------------
Problem: Layer mask doesn't include Agent
Expected Values:
→ Agent layer = 6 (bit 6)
→ Target layer = 3 (bit 3)
→ HitMask = (1 << 6) | (1 << 3) = 64 + 8 = 72

If HitMask value is wrong:
→ Explosion won't detect players!

Fix:
Update _explosionHitMask to include Agent layer

================================================================================
LAYER MASK CALCULATION
================================================================================

Unity Layers (from context):
-----------------------------
0: Default
1: TransparentFX
2: Ignore Raycast
3: Target
4: Water
5: UI
6: Agent ← PLAYERS!
7: Projectile
8: FPV
9: AgentKCC
10: Interaction
11: Pickup
12: MapOnly
13: Storm

Layer Mask Bits:
----------------
Target (layer 3) = 1 << 3 = 8
Agent (layer 6) = 1 << 6 = 64

Combined Mask:
--------------
Agent + Target = 64 + 8 = 72

Your HitMask should be 72!

If you see different value in logs:
→ That's the problem!

================================================================================
QUICK DIAGNOSIS
================================================================================

Run this mental checklist:

[ ] Did explosion happen? (effect visible)
    → If no: collision not working
    
[ ] Were colliders found? (check "Found X colliders")
    → If 0: layer mask or distance issue
    
[ ] Was owner detected? (check "Owner: [name]")
    → If null: owner not set in Fire()
    
[ ] Was IHitTarget found? (no "No IHitTarget" log)
    → If missing: player prefab issue
    
[ ] Was isSelf = true? (check "IsSelf: true")
    → If false: wrong agent comparison
    
[ ] Was damage applied? (check "Applying X damage")
    → If missing: damage calculation issue
    
[ ] Was damage reduced? (should be 75% of base)
    → If not: self damage multiplier not applied

Find which step fails → that's your issue!
