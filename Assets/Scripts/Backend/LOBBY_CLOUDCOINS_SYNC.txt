================================================================================
HOW IT WORKS
================================================================================

When Lobby Opens:
-----------------
1. UIFortniteLobbyView.OnOpen() is called
2. Calls LoadPlayerDataFromBackend()
3. PlayerDataManager.LoadPlayerData() fetches from backend
4. Updates CloudCoinsText with current coin amount
5. Updates LevelText with current level
6. Updates level progress bar with XP

When Coins Change:
------------------
1. Player earns coins (e.g., from shop purchase, match reward)
2. PlayerDataManager.AddCoins() is called
3. Backend updates player JSON
4. OnCoinsChanged event fires
5. Lobby UI automatically updates display ✓

When Level Up:
--------------
1. Player gains XP
2. PlayerDataManager.AddXP() is called
3. Backend calculates new level
4. OnLevelChanged event fires
5. Lobby UI updates level display ✓

================================================================================
MANUAL COIN UPDATE (For Testing)
================================================================================

In Unity Console, you can manually update coins:

Add Coins:
----------
PlayerDataManager.Instance.AddCoins(1000, (success, newTotal) => {
    Debug.Log($"New total: {newTotal}");
});

Set Specific Amount:
--------------------
// Deduct current amount, then add new amount
var current = PlayerDataManager.Instance.CurrentData.CloudCoins;
PlayerDataManager.Instance.AddCoins(-current);
PlayerDataManager.Instance.AddCoins(5000);

Add XP:
-------
PlayerDataManager.Instance.AddXP(1500, (success, level, xp) => {
    Debug.Log($"Level: {level}, XP: {xp}");
});

INTEGRATION WITH GAME SYSTEMS

After Match:
------------
public class MatchRewards : MonoBehaviour
{
    public void OnMatchEnd(int placement, int kills)
    {
        int coinsEarned = CalculateReward(placement, kills);
        PlayerDataManager.Instance.AddCoins(coinsEarned);
        
        // Lobby will auto-update when player returns!
    }
}

In Shop:
--------
public class ShopPurchase : MonoBehaviour
{
    public void BuyItem(int cost)
    {
        PlayerDataManager.Instance.AddCoins(-cost, (success, newTotal) => {
            if (success)
            {
                Debug.Log($"Purchased! {newTotal} coins remaining");
                // Lobby already updated automatically!
            }
        });
    }
}

    }

================================================================================
LEVEL AND XP DISPLAY
================================================================================

Level Text:
-----------
Shows: "Level 25"
Updates automatically when player levels up

XP Progress Bar:
----------------
- Displays XP progress toward next level
- Fills from 0 to 1 (0 XP to 1000 XP)
- XP per level is 1000 (configured in backend)
- Resets on level up

Example:
Level 10, 250 XP → Bar is 25% filled
Level 10, 500 XP → Bar is 50% filled
Level 10, 750 XP → Bar is 75% filled
Level 10, 1000 XP → Level up to 11, bar resets to 0%
