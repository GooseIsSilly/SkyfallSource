================================================================================
WHAT WAS FIXED
================================================================================

Problem #1: Rigidbody was Kinematic
------------------------------------
Kinematic rigidbodies don't trigger OnCollisionEnter!
The rocket would pass through objects without detecting collision.

Fixed:
✅ Set isKinematic = false
✅ Set collisionDetectionMode = Continuous
✅ Set interpolation = Interpolate

Problem #2: Projectile Speed Too High
--------------------------------------
Speed was 100 m/s (too fast, like a bullet!)
Rockets should be slow and visible.

Fixed:
✅ Set projectileSpeed = 30 m/s (Fortnite-like)

Problem #3: Collider Too Large
-------------------------------
Sphere collider radius was 0.5 (too big)
Could hit things unexpectedly.

Fixed:
✅ Set radius = 0.2 (appropriate for rocket)

Problem #4: Projectile Inactive
--------------------------------
Prefab was set to inactive by default.

Fixed:
✅ Set activeSelf = true

================================================================================
EXPLOSION DAMAGE CALCULATION
================================================================================

How Damage Works:
-----------------

1. Explosion occurs at impact point
2. OverlapSphere finds all colliders in radius
3. For each target found:
   - Calculate distance from explosion center
   - Calculate damage multiplier: 1 - (distance / radius)
   - Apply damage: baseDamage * multiplier
   - If self-damage: multiply by 0.75

Example:
--------
Base Damage: 100
Explosion Radius: 8.35m

Target at 0m (direct hit): 100 damage ✓
Target at 2m: 76 damage
Target at 4m: 52 damage
Target at 6m: 28 damage
Target at 8m: 4 damage
Target at 9m: 0 damage (outside radius)

Self damage at 2m: 57 damage (76 * 0.75)

Perfect falloff! ✓
