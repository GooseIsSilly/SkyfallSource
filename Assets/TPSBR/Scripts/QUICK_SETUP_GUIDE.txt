STEP 1: ADD FORTNITE TRAIL (2 MINUTES)
================================================================================

Option A: Automatic Setup (Easiest!)
-------------------------------------

1. Find your rocket projectile prefab
   (Search for "RocketProjectile" or check /Assets/TPSBR/Prefabs/Projectiles/)

2. Open the prefab

3. Add FortniteRocketTrail component:
   - Click "Add Component"
   - Search: "FortniteRocketTrail"
   - Add it!

4. Configure in Inspector:
   Create Light: ✓ (checked)
   Glow Color: Orange (255, 153, 0)
   Glow Intensity: 2
   Trail Time: 0.5
   Trail Width Start: 0.3
   Trail Width End: 0.05

5. Save prefab

DONE! ✓

The script automatically creates:
✓ Glowing orange trail
✓ Point light that follows rocket
✓ Gradient color (orange to red)
✓ Fortnite-style visuals!

Option B: Manual Setup
----------------------

1. Find rocket projectile prefab

2. Add TrailRenderer component:
   - Time: 0.5
   - Width: 0.3 → 0.05 (curve)
   - Color: Orange → Red → Transparent (gradient)
   - Material: Particles/Additive shader

3. Add Light component:
   - Type: Point
   - Color: Orange
   - Range: 5
   - Intensity: 2

4. Save prefab

DONE! ✓

================================================================================
STEP 2: CREATE EXPLOSION EFFECT (Optional - 3 Minutes)
================================================================================

Quick Setup:
------------

1. Create new GameObject: "RocketExplosion"

2. Add Particle System:
   - Duration: 1
   - Start Lifetime: 0.5
   - Start Speed: 0
   - Start Size: 1 → 8
   - Start Color: Orange
   - Emission: Burst 50
   - Color Over Lifetime: Orange → Red → Black
   - Size Over Lifetime: Expand curve

3. Add Light:
   - Type: Point
   - Color: Orange
   - Range: 20
   - Intensity: 8

4. Add Audio Source:
   - Assign explosion sound
   - Play On Awake: True
   - Spatial Blend: 3D

5. Save as Prefab

6. Assign to RocketProjectile:
   - Open RocketProjectile prefab
   - Find RocketProjectile component
   - Explosion Effect: Drag your explosion prefab

DONE! ✓

Or use existing explosion effects in your project!
