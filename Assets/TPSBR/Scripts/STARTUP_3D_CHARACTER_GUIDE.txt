HOW TO USE
================================================================================

Option 1: Use 2D Images (Current/Default)
------------------------------------------
1. Select StartUpManager in Startup scene
2. Uncheck "Use 3D Characters"
3. Assign Character Image sprite
4. Optionally assign Second Character Image
5. Done! Works like before ✓

Option 2: Use 3D Character Models (NEW!)
-----------------------------------------
1. Select StartUpManager in Startup scene
2. ✅ Check "Use 3D Characters"
3. Assign Character Model (e.g., MenuSoldier prefab)
4. Set Animation State Name (e.g., "Idle")
5. Adjust Character Position/Rotation/Scale
6. Play scene! ✓

================================================================================
POSITIONING THE CHARACTER
================================================================================

Character Position:
-------------------
X: Left/Right   (default: 2)
Y: Up/Down      (default: -1)
Z: Forward/Back (default: 3)

Recommended Positions:
Single Character:  (0, -1, 3)
Main Character:    (2, -1, 3)
Second Character:  (-2, -1, 4)

Character Rotation:
-------------------
X: Pitch  (default: 0)
Y: Yaw    (default: 180 = facing camera)
Z: Roll   (default: 0)

Facing Camera: (0, 180, 0)
Profile View:  (0, 135, 0) or (0, 225, 0)

Character Scale:
----------------
1 = Normal size
1.5 = Bigger
0.75 = Smaller

================================================================================
TROUBLESHOOTING
================================================================================

Character doesn't appear:
-------------------------
- Check "Use 3D Characters" is enabled
- Check Character Model is assigned
- Check character position isn't off-screen
- Check character scale isn't 0

Animation doesn't play:
-----------------------
- Check Animation State Name is correct
- Check character has Animator component
- Check Animator has controller assigned
- Try "Idle" - most models have this

Character facing wrong way:
---------------------------
- Change Y rotation to 180 (facing camera)
- Or try 0, 90, 270 for different angles

Character too big/small:
------------------------
- Adjust Character Scale
- Try 0.8 for smaller, 1.2 for bigger

Second character doesn't show:
-------------------------------
- Check "Show Second Character" is enabled
- Check Second Character Model is assigned
- Check position isn't overlapping main character

================================================================================
ADVANCED CUSTOMIZATION
================================================================================

Different Animations per Character:
------------------------------------
Currently both use same animation.
To use different animations, modify LevelManager:

In Spawn3DCharacters(), change:
PlayAnimation(secondCharacterAnimator, "Walk");
                                       ↑
                             Different animation!

Random Animations:
------------------
string[] animations = {"Idle", "Wave", "Dance"};
string randomAnim = animations[Random.Range(0, animations.Length)];
PlayAnimation(characterAnimator, randomAnim);

Animated Movement:
------------------
Add this to Update():
if (spawnedCharacter != null)
{
    spawnedCharacter.transform.Rotate(0, 30 * Time.deltaTime, 0);
}

Result: Character slowly spins
