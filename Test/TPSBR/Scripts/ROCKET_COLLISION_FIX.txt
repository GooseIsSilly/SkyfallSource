PROBLEM: Rocket flew straight but didn't explode on impact
CAUSE: Collision system conflict between KinematicProjectile and RocketProjectile
SOLUTION: Override collision system to use OnCollisionEnter!

================================================================================
THE ROOT CAUSE
================================================================================

What Was Happening:
-------------------
1. RocketProjectile extends KinematicProjectile
2. KinematicProjectile uses raycast-based collision in FixedUpdateNetwork()
3. RocketProjectile has OnCollisionEnter() method
4. Both systems were fighting each other!
5. Base class handled collision first
6. OnCollisionEnter() never triggered
7. No explosion! ❌

The Conflict:
-------------
KinematicProjectile.FixedUpdateNetwork():
→ Uses ProjectileUtility.ProjectileCast()
→ Raycast-based collision detection
→ Processes hit immediately
→ Doesn't trigger OnCollisionEnter

RocketProjectile.OnCollisionEnter():
→ Waits for Unity Physics collision
→ Checks arming delay
→ Calls Explode() method
→ NEVER GETS CALLED! ❌

================================================================================
THE FIX
================================================================================

What I Changed:
---------------
✅ Overrode FixedUpdateNetwork() in RocketProjectile
✅ Disabled base KinematicProjectile collision system
✅ Use only OnCollisionEnter() for rocket collisions
✅ Apply velocity directly via Rigidbody
✅ Maintain constant rocket speed
✅ Handle timeout despawn separately

Now RocketProjectile:
---------------------
1. Spawns with Rigidbody.linearVelocity set
2. Maintains 30 m/s constant velocity
3. Unity Physics handles movement
4. OnCollisionEnter() triggers on impact
5. Checks arming delay (0.2s)
6. Calls Explode() method
7. BOOM! ✓

CODE CHANGES
================================================================================

Fire() Method:
--------------
OLD:
base.Fire(owner, firePosition, initialVelocity, hitMask, hitType);

NEW:
// Set velocity directly on rigidbody
var rb = GetComponent<Rigidbody>();
if (rb != null)
{
    rb.linearVelocity = initialVelocity;
    transform.position = firePosition;
}

Result: Direct physics-based movement! ✓

FixedUpdateNetwork() Method (NEW):
-----------------------------------
// Don't use base KinematicProjectile collision system
// Rocket uses OnCollisionEnter instead

// Maintain constant velocity
if (_rigidbody != null && !_rigidbody.isKinematic)
{
    Vector3 velocity = _rigidbody.linearVelocity;
    if (velocity.magnitude < _rocketSpeed * 0.9f)
    {
        _rigidbody.linearVelocity = velocity.normalized * _rocketSpeed;
    }
}

// Check for timeout despawn
if (Time.time - _spawnTime > FireDespawnTime)
{
    Runner.Despawn(Object);
}

Result: Maintains speed, handles timeout! ✓

OnCollisionEnter() Method (Unchanged):
---------------------------------------
protected void OnCollisionEnter(Collision collision)
{
    if (HasStateAuthority == false)
        return;

    if (Time.time - _spawnTime < _armingDelay)
        return;  // Too early to explode

    Explode(collision.contacts[0].point, collision.contacts[0].normal);
}

Result: NOW TRIGGERS! ✓

================================================================================
ARMING DELAY SYSTEM
================================================================================

How It Works:
-------------
1. Rocket spawns
2. _spawnTime = Time.time (recorded)
3. Rocket flies
4. Collision occurs
5. OnCollisionEnter() checks: Time.time - _spawnTime > 0.2s?
6. If yes → Explode!
7. If no → Ignore collision, keep flying

Purpose:
--------
✓ Prevents instant self-kill
✓ Rocket must travel ~6m (0.2s × 30 m/s)
✓ Safe to fire at ground
✓ Still can rocket jump from distance!

Fortnite has this too! ✓

================================================================================
EXPLOSION SYSTEM
================================================================================

Explode() Method Flow:
----------------------
1. Spawn explosion effect at impact point
2. Physics.OverlapSphere(position, 8.35m radius)
3. For each collider found:
   a. Get IHitTarget component
   b. Calculate distance from explosion
   c. Calculate damage: base × (1 - distance/radius)
   d. Apply damage with falloff
   e. Check if self-damage (75% multiplier)
   f. ProcessHit() on target
4. Runner.Despawn(rocket)

Result:
-------
✓ Large area damage
✓ Damage falloff from center
✓ Self-damage possible
✓ Multiple targets hit
✓ Just like Fortnite! ✓
