================================================================================
WHERE MESSAGES APPEAR
================================================================================

1. Login Screen
   → Player tries to login
   → Shows ban message in feedback text

2. Auto-Login (Saved Token)
   → Game tries to auto-login with saved token
   → Shows ban message if account is banned
   → Clears saved credentials

3. In-Game Detection
   → Player gets banned while playing
   → BanCheckService kicks them within 30 seconds
   → Shows ban message

================================================================================
CUSTOMIZATION
================================================================================

To change the message format, edit FormatBanMessage() in BackendServiceManager.cs:

Current:
--------
"YOU ARE BANNED\n\nReason: {reason}\n\nBan Duration: Until {time}"

You can change to:
------------------
"⛔ ACCOUNT SUSPENDED ⛔\n\n📋 {reason}\n\n⏰ {time}"

Or more formal:
---------------
"Access Denied\nViolation: {reason}\nReinstated: {time}"

Or friendly:
------------
"Oops! Your account is temporarily suspended\nWhy? {reason}\nWhen can you return? {time}"
