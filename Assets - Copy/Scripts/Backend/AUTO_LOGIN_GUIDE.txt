================================================================================
TROUBLESHOOTING
================================================================================

Problem: Always shows login panel
Solution:
- Check "Auto Login On Start" is enabled
- Check BackendServiceManager exists in scene
- Check backend URL is correct
- Check backend is running

Problem: Loading panel never hides
Solution:
- Check backend is responding
- Check network connection
- Check backend URL is correct
- Look at console for errors

Problem: Token validation fails
Solution:
- Backend might have restarted (tokens lost)
- Account might be banned
- Just login again - it will save new token

Problem: Auto-login works once, then fails
Solution:
- Backend restarted (tokens in memory)
- This is normal for development
- Production backends should persist tokens

================================================================================
HOW IT WORKS TECHNICALLY
================================================================================

Token Storage:
--------------
- Token saved in PlayerPrefs (persistent)
- Key: "AuthToken"
- Username also saved: "Username"
- Survives game restart

Auto-Login Flow:
----------------
1. Start() → TryAutoLogin()
2. Check HasStoredToken()
3. Call ValidateToken() → backend endpoint
4. Backend checks if token valid
5. If yes → OnLoginSuccess() → show game
6. If no → ShowLoginPanel() → user logs in

Backend Endpoint:
-----------------
GET /login/connectbytoken?Token=XYZ
Returns:
- {"log": "ok", "username": "player"} → valid
- {"log": "TokenDoesNotExist"} → invalid
- {"log": "AccountBanned", ...} → banned
