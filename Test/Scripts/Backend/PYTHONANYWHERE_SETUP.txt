STEP 5: CONFIGURE WSGI FILE FOR PYTHONANYWHERE
================================================================================

PythonAnywhere needs a special WSGI file!

1. Go to "Web" tab
2. Find "Code:" section
3. Click on "WSGI configuration file" link
4. It will open an editor

REPLACE ALL CONTENT with this:

```python
import sys
import os

# Add your project directory to the sys.path
path = '/home/YOURUSERNAME/mysite'  # ← Change YOURUSERNAME!
if path not in sys.path:
    sys.path.append(path)

# Change working directory
os.chdir(path)

# Import your FastAPI app
from Account import app

# This is the WSGI application object
application = app
```

IMPORTANT: Change "YOURUSERNAME" to your actual username!

Save the file (Ctrl+S or Save button)

STEP 6: FIX ACCOUNT.PY FOR PYTHONANYWHERE
================================================================================

Your Account.py needs small changes for PythonAnywhere!

Change #1: Remove uvicorn.run() at bottom
-------------------------------------------
FIND this at the end:
if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)

CHANGE TO:
if __name__ == "__main__":
    pass  # PythonAnywhere uses WSGI instead

Change #2: Fix file paths to be absolute
-----------------------------------------
FIND:
with open("Accounts/" + ID + ".json", "r") as savefile:

CHANGE TO:
import os
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
accounts_path = os.path.join(BASE_DIR, "Accounts", ID + ".json")
with open(accounts_path, "r") as savefile:

Do this for ALL file operations!

Change #3: Remove CORS * (optional but recommended)
----------------------------------------------------
FIND:
allow_origins=["*"],

CHANGE TO:
allow_origins=["https://novafy.pythonanywhere.com"],
